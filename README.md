# PetCare

Python/FastAPI + PostgreSQL или MySQL + React/TypeScript. Схема базы управляется Alembic.

[Архитектура](docs/ARCHITECTURE.md) · [Панель администратора](docs/ADMIN.md).

Базовая защита, отдельные роли БД и подготовка offsite backup: [docs/SECURITY.md](docs/SECURITY.md).

## Запуск и миграция

Frontend: [структура React/TS, сборка и разработка](docs/FRONTEND.md). Для сборки нужен Node.js 22.12+.

Размещение и перенос SQLite: [PostgreSQL](docs/POSTGRESQL.md) и [MySQL на REG.RU](docs/MYSQL_HOSTING.md).

```sh
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r app/requirements.txt
npm ci
npm run build
# Настройте закрытый app/.env по app/.env.example и создайте базу PostgreSQL или MySQL.
python -m alembic upgrade head
python -m uvicorn main:app --app-dir app --host 127.0.0.1 --port 8000
```

Для существующего SQLite не запускайте сервис с пустой базой: сначала выполните перенос по инструкции. `DATABASE_URL` обязателен; SQLite больше не выбирается автоматически. Файлы `.env`, `data/` и резервные копии не публикуются.

- `app/` — приложение, API, серверные уведомления и тесты.
- `app/frontend/` — исходники React/TypeScript и переходный JavaScript-модуль.
- `app/static/frontend/` — сгенерированная production-сборка (создаётся через `npm run build`).
- `migrations/` — версии схемы Alembic.
- `app/transfer_sqlite.py` — проверяемый перенос всех данных SQLite в пустую PostgreSQL или MySQL.
- `compose.yaml` — локальный PostgreSQL 17.
- `backup.py` — приватные резервные копии PostgreSQL и MySQL.
- `setup_hosting.py` — зависимости, миграции схемы и Passenger. Требует настроенную базу, перенос SQLite запускается отдельно.
- `app/bootstrap_admin.py` — явное создание первого администратора из закрытого JSON, если данные ещё не перенесены.

Тесты запускаются на отдельной базе через `TEST_DATABASE_URL`; порядок — в [docs/CI_CD.md](docs/CI_CD.md). Не используйте рабочую базу для API или браузерных тестов.

## Язык интерфейса

PetCare поддерживает русский и английский. При первом открытии выбирается первый поддерживаемый язык из настроек браузера. Если среди них нет русского или английского, открывается английская версия. Переключатель доступен на гостевом экране и в профиле. Выбор сохраняется в браузере.

## Серверные уведомления

Установщик создаёт ключи VAPID. В планировщике хостинга нужно создать запуск **каждую минуту**, с полными реальными путями:

```sh
/ПУТЬ/К/ПРОЕКТУ/.venv/bin/python /ПУТЬ/К/ПРОЕКТУ/app/notifications.py
```

Процесс отправляет Web Push подписанным устройствам и, при желании пользователя, письма. Есть тихие часы, выбранные категории, истечение подписок и защита от повторной отправки при одновременных запусках cron. После сбоя доставки делается следующая попытка; это не сервис гарантированной доставки. При закрытом браузере уведомления зависят от разрешений и возможностей ОС. На iPhone Web Push требует поддерживаемую версию iOS и установленное веб-приложение.

При добавлении события системное разрешение не запрашивается. Уведомления внутри PetCare и настройка фоновых уведомлений включены по умолчанию. Для фоновой доставки устройству требуется разрешение браузера и работающий cron.

Центр уведомлений в профиле хранит напоминания, сформированные планировщиком, и сообщения администратора. Рассылка публикуется сразу в центре уведомлений существующих аккаунтов. Планировщик отправляет push подписанным устройствам. Перед публикацией обновления примените миграцию `20261126_inbox` и направьте задачу cron на установленную версию приложения.

## Почта и ИИ

`app/.env.example` перечисляет параметры SMTP и Gemini. Ключ `GEMINI_API_KEY` хранится только в закрытом `app/.env` на сервере, вне публичной папки и Git. `GEMINI_MODEL=gemini-3.5-flash-lite` — фиксированная модель с бесплатным тарифом. Используйте проект Google AI Studio **Free tier без подключённого Cloud Billing**. Подписка Google AI Pro не заменяет тариф API. Если впоследствии подключить Cloud Billing, действуют тарифы Google: приложение не может отключить биллинг в чужом аккаунте.

Автоматическая подмена модели отключена. При исчерпании бесплатной квоты показывается ошибка, платный запасной сервис не вызывается. Фото уходит в Google только после отдельного согласия в форме. На бесплатном тарифе Google может использовать данные для улучшения своих продуктов. Результат человек проверяет и редактирует перед использованием; данные не добавляются в назначения автоматически. Модель получает инструкции распознавать печатный и рукописный текст, помечать сомнительные и неразборчивые фрагменты и не придумывать дозировки.

Лимиты приложения: 10 запросов на пользователя и 40 суммарно в сутки. Отсутствующий ключ и неверный формат файла не расходуют эти лимиты. Ограничения самого Google могут быть меньше.

SMTP: SSL на порту 465 либо STARTTLS на 587 с проверкой сертификатов. Без SMTP недоступны новая регистрация и коды по почте.

## Доступы и тарифы

Бесплатный аккаунт: один питомец суммарно (свой или активный совместный). Расширенный: больше питомцев и ИИ. При отзыве доступа существующие питомцы не удаляются, но добавить сверх лимита нельзя.

Администратор работает в отдельной тёмной панели `/admin`. Там доступны пользователи, история входов, роли, тарифы, блокировки, нагрузка сервера, контакт поддержки и журнал действий. Самостоятельная регистрация требует почтовый код. Администратор может создать аккаунт вручную. Подробнее в [руководстве администратора](docs/ADMIN.md).

**Оплата не подключена**: выдача доступа ручная, списания и подписки не создаются.
