# Панель администратора PetCare

Панель открывается по адресу `/admin` или после входа через обычную форму с учётной записью администратора. Язык можно выбрать на экране входа и в самой панели.

- Пользователи. Поиск по имени или почте, управление доступом к Premium, блокировки и завершение сеансов.
- Поддержка. Контакт для обращения пользователей редактируется в настройках панели.
- Состояние сервера. Панель показывает загрузку процессора, использование памяти и доступное место. Данные обновляются каждые 10 секунд при открытой вкладке.
- Журнал действий. Изменения в панели записываются в журнал.
