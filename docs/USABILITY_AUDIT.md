## Проверка

- 46 тестов API прошли.
- forms_browser.py и ux_browser.py: 1440×900, 375×812, 812×375.
- usability_browser.py: меню 320/375/812/1023px, клавиатурный фокус, длинные имена/породы, несохранённые изменения, отказ сервера при сохранении/удалении, отмена удаления, отказ буфера, ошибка и ожидание входа.
- Тесты используют отдельную демонстрационную базу; ошибки сервера моделируются перехватом запросов.

Это проверка основных сценариев, а не сертификация WCAG. Физические устройства с экранной клавиатурой, VoiceOver/TalkBack, все сочетания масштабирования и полный инструментальный аудит контраста требуют отдельной проверки. Цветовая тема проекта светлая.
