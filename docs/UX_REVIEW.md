# Изменения по обзорной оценке PetCare

- Карточки питомцев показывают название и дату первой просроченной процедуры, число просрочек и переход к фильтру «Просрочено». Открытие карточки и копирование кода доступны отдельными кнопками.
- В каталоге добавлена сводка «Сегодня» для выбранного питомца с процедурами и ссылкой на кормления.
- Редактирование профиля здоровья свёрнуто; журнал и сравнение кормов, история и покупки, клиника и дневник раскрываются по запросу.
- Сравнение требует два разных корма, при недостатке записей предлагает добавить корм.
- Основное меню использует ссылки с отдельными доступными именами. Действия ухода и покупки включают название записи в доступное имя.
- Однократное напоминание не показывает и не отправляет интервал; повтор требует положительный интервал с подписью в днях или месяцах.
- Часовой пояс выбирается в настройках аккаунта. Ввод расписания остаётся явно московским; рядом отображается соответствующее время в выбранном поясе. Полный перевод ввода расписаний и кормлений на местное время не входит в эту правку.
- В документах есть поиск по названию, имени файла, категории и дате, а вложение из здоровья ведёт к медицинской записи.
- Пустое состояние поиска друзей объясняет появление новых анкет и роль настроек профиля.
- Закрытие изменённой модальной формы требует подтверждения. После закрытия фокус возвращается стандартным поведением dialog. Это не глобальная защита от несохранённых изменений во всех встроенных формах.

## Проверка

46 существующих тестов приложения проходят. `tests/ux_browser.py` проверяет новые сценарии на ширинах 1440 и 390 px: фильтр просрочек, ссылки, свёрнутый профиль, форму повтора, возврат фокуса, сравнение и поиск документов, ошибки JavaScript и горизонтальное переполнение. Browser-тест запускается отдельной задачей GitHub Actions.

Для локального запуска нужны зависимости из app/requirements.txt и tests/requirements-ui.txt,
`python -m playwright install chromium`, запущенный localhost:8002 с ENABLE_DEMO_LOGIN=true и отдельной DATABASE_URL. Затем `python tests/ux_browser.py`.
Не запускайте эту проверку на рабочем сайте: она использует демо-вход. Сценарий проверки формы корма создаёт тестовую запись в изолированной базе; остальные контролируемые данные меняются в памяти страницы. Используйте только тестовый сервер.

Мобильная проверка выполнена эмуляцией viewport в Chromium. Поведение экранной клавиатуры iOS/Android и полный аудит контраста требуют проверки на физических устройствах.

## Удобство журнала кормов

Форма добавления корма разделена на информацию о продукте, наблюдения и свёрнутые дополнительные сведения. Оценки выбираются крупными нативными радиокнопками с клавиатурной навигацией; по умолчанию оценка неизвестна. Название обязательно, реакции и дополнительные сведения необязательны. Кнопка сохранения закреплена внизу окна. В журнале отдельно показаны аппетит, переносимость и наблюдения; цвет сопровождается текстом. Добавление корма вынесено в верхнюю часть раздела, расписание кормлений доступно отдельным действием.

Браузерный тест проверяет отправку формы и отображение результата на 1440×900, 375×812 и 812×375 при reduced-motion.

## Общие формы, календарь и навигация

Остальные модальные формы используют секции с заголовками, читаемые поля и закреплённые действия. Общие размеры полей применены также к входу, безопасности, карточке питомца и анкете знакомств. Поля и обработчики сохранения остаются прежними.

Календарь поддерживает ручной ввод ДД.ММ.ГГГГ с проверкой существования даты, быстрые варианты «Сегодня», «Завтра», «Через неделю», переход по дням стрелками и открытие клавишей Enter. Время проверяется перед подтверждением, после выбора фокус возвращается в исходное поле. Учитываются min/max/step исходного поля.

На экранах до 1023px круглая кнопка «Питомцы» расположена в центре нижнего меню; все шесть разделов сохранены.

`tests/forms_browser.py` проверяет открытие всех типов формы, ограничения даты и времени, високосный день, клавиатуру и геометрию центральной кнопки на трёх размерах. Запускается в задаче Interface (desktop and mobile) после ux_browser.py.

## Временная пауза раздела «Друзья»

`FRIENDS_ENABLED = false` в app/index.html скрывает пункт меню и сам раздел, убирает переход из карточки питомца и останавливает фоновую загрузку подбора. Старые ссылки на раздел открывают каталог питомцев. При пяти видимых пунктах круглая кнопка «Питомцы» остаётся в центре нижнего меню.

Для возврата раздела установите FRIENDS_ENABLED = true. Разметка, серверные API и данные анкет сохранены. Это пауза пользовательского раздела, а не блокировка API на сервере.
