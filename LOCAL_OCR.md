# Распознавание печатных документов

Сайт использует Tesseract.js 6.0.1 / core 6.0.0 в браузере, русский и английский языки. API-ключ, оплата, внешняя отправка фото не нужны. Рукописный текст не поддерживается. Файлы движка и языков загружаются с самого сайта, только после нажатия кнопки. Языки кэшируются движком на устройстве; фото и результат в этот кэш не записываются.

Перед развёртыванием выполните `python3 tools/fetch_ocr_assets.py` из исходников. Требуются Python 3 и curl. Все версии и SHA-256 закреплены в `tools/ocr-assets.json`; лицензии движка включены в загрузку. Полученная папка `app/static/ocr/vendor/` должна быть скопирована на хостинг вместе с `app/static/local-ocr.js`. Крупные готовые файлы не хранятся в Git, их восстанавливает скрипт.

В интерфейсе доступ проверяется через авторизованный `/api/v1/billing/status`; бесплатные аккаунты сохраняют лимит 3 питомцев, администратор выдаёт premium. Движок исполняется на компьютере пользователя, поэтому это ограничение интерфейса PetCare, а не защита общедоступного открытого движка от самостоятельного использования.

Обработка: чтение ориентации EXIF, ручной поворот, масштабирование до 2600 px по длинной стороне, оттенки серого, мягкое растяжение контраста. Максимум 10 МБ / 40 Мп. Индикатор прогресса, ограничение времени, освобождение worker после каждого запроса. Низкая уверенность помечается; названия, числа и дозировки автоматически не исправляются. Пользователь должен сверять результат с документом.

Проверено в браузере на синтетическом русском и английском печатном документе: имя Барсик, вес 4.5 кг, дата 13.11.2026, confidence 94. Реальные размытые фото и почерк могут распознаваться неверно. Старый серверный Gemini API сохранён для совместимости исходников, новый интерфейс к нему не обращается и не передаёт фото на сервер.
